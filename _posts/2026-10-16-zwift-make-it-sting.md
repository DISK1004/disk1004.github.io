## 練習内容

今日は朝からAS京都のスイム練習に参加する予定でしたが、寝坊してしまいました。

スイムには行けなくなりましたが、何もしないのはもったいないので、Zwiftでバイクトレーニングを実施しました。

選択したワークアウトは「Make It Sting」。

短時間ながら、強度に変化のあるメニューに取り組みました。

## トレーニングデータ

| 項目 | 結果 |
|---|---|
| 種目 | インドアバイク（Zwift） |
| ワークアウト | Make It Sting |
| 時間 | 24分03秒 |
| 平均パワー | 161W |
| NP | 190W |
| 平均心拍数 | 122bpm |
| 最大心拍数 | 156bpm |
| 運動負荷 | 54 |
| 有酸素トレーニング効果 | 2.6 |

## トレーニング効果

### 短時間でのバイク強化

平均パワー161Wに対して、ノーマライズドパワーは190Wでした。

出力に変化のあるワークアウトで、短時間ながら負荷をかけることができました。

有酸素トレーニング効果は2.6。

約24分間の練習でしたが、バイクのトレーニング刺激を入れることができました。

### ODサブ2時間30分に向けて

現在の最優先目標は、オリンピックディスタンスで2時間30分を切ることです。

目標タイムは以下のとおりです。

- スイム1500m：33〜35分
- バイク40km：1時間10〜12分
- ラン10km：39〜40分
- トランジション合計：5分以内

バイクではFTP240Wを中間目標、250Wを最終目標としています。

今後もスイムを最優先にしながら、バイクの出力向上に取り組んでいきます。

## 振り返り

今日は寝坊してしまい、予定していたスイム練習ができませんでした。

スイムが最大の課題なので、練習機会を逃してしまったのは残念です。

それでも、Zwiftで24分間のバイクトレーニングを実施できたことは良かったと思います。

仕事のある日でも、短時間のトレーニングなら取り組むことができます。

今後は朝の時間管理にも気をつけながら、スイムとバイクの強化を継続していきたいと思います。
