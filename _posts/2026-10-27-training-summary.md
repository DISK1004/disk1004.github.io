## トレーニング効果

### 1. FTP227Wを記録

今回の期間で最も重要だったのは、10月25日のFTP Ramp Testです。

測定FTPは227Wとなりました。

中間目標の240Wまでは13W、最終目標の250Wまでは23Wです。

今後はFTP227Wを基準にZwiftのトレーニング強度を設定していきます。

### 2. バイクの有酸素持久力強化

10月24日のSSTと25日のFTPテストでは比較的高い強度の運動を実施しました。

一方、26日と27日は強度を抑えたライドを実施しています。

10月27日のGarminによるトレーニング効果は以下のとおりです。

| 指標 | 結果 |
|---|---:|
| 有酸素TE | 2.7 |
| 無酸素TE | 0.0 |
| TSS | 41.6 |
| 運動負荷 | 61 |
| 主な利点 | ベース |

### 3. ランニング能力の維持

10月21日には15.22kmのランニングを実施しました。

ランニングは能力維持を優先し、今後もスイムとバイクの練習を中心に組み立てていきます。

### 4. スイム休止への対応

現在、足の接触性皮膚炎によってスイム練習を休止しています。

スイム1500mを33〜35分で泳ぐことが当面の目標ですが、皮膚炎が回復するまでは無理にプールへ戻らない方針です。

### 5. 休養日の確保

10日間のうち5日間は完全休養でした。

練習量としては多くありませんが、皮膚炎がある状況で無理に練習を増やすことは避けたいと考えています。

## 振り返り

今回の10日間は、スイム練習ができない状況でのトレーニングとなりました。

休養日も多く、通常のトライアスロン練習とは異なる内容でしたが、バイクではFTP227Wを記録できました。

中間目標の240Wまで残り13Wとなり、今後のバイク強化に向けた具体的な目標ができました。

現在の目標は以下のとおりです。

| 種目 | 目標 |
|---|---|
| スイム1500m | 33〜35分 |
| バイク40km | 1時間10〜12分 |
| ラン10km | 39〜40分 |
| トランジション | 合計5分以内 |
| FTP | 240W → 250W |

まずは皮膚炎を治して、スイム練習に復帰することを優先します。

それまではバイクのFTP向上とランニング能力の維持に取り組んでいきます。

**目標はオリンピックディスタンス2時間30分切り。**

練習できない種目がある中でも、できることを継続していきたいと思います。
